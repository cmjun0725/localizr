저장 완료 "Saved" "Changes saved"왜? 저장을 알리는 문구는 목적어를 붙여야 안심이 됩니다.
에러 메시지 "Cannot connect to server. Please try again later." "We couldn't reach our servers. Please try again in a moment."왜? 미국 앱은 "We" 주어를 써서 사용자와 같은 편임을 보여줍니다.
확인 버튼 "Confirmation" "Got it"왜? 확인 버튼은 "OK"보다 친근한 "Got it"이 더 많이 쓰입니다.
다음 단계 버튼 "Next" "Continue"왜? 결제·가입 흐름에서는 Next보다 Continue가 전환율이 높습니다.

구글 번역기와 다른 점 3가지

단순 번역이 아니라 "현지인의 눈"으로 보는 도구입니다

🎯

맥락을 안다

"이 문구는 어느 화면의 버튼인가", "결제 단계인가"를 알면 번역이 달라집니다. 같은 한국어도 상황에 따라 다른 영어가 됩니다.

📏

문자 수 제한 반영

버튼은 15자, 앱스토어 제목은 30자. 잘리는 걸 알면서 번역해주는 도구는 거의 없습니다. Localizr는 제한 안에서 자연스러운 문구를 제안합니다.

💡

왜 그런지 알려준다

모든 제안에 한국어 설명이 붙습니다. 그래서 개발자가 그냥 복붙하는 게 아니라 "이제부터는 영어를 스스로 판단"할 수 있게 됩니다.

3단계면 끝

회원가입 복잡한 과정 없이, 붙여넣고 결과 받기만 하면 됩니다

1

앱 문구 붙여넣기

JSON 파일이나 문구 목록을 그대로 붙여넣습니다. 100개든 1,000개든 상관없습니다.

2

컨텍스트 선택

"버튼 / 에러 / 안내 문구 / 앱스토어 리스팅" 중 어디에 쓰이는지 고르기만 하면 됩니다.

3

자연스러운 영어 받기

현지인 눈에 자연스러운 번역 + 왜 그렇게 바뀌었는지 한국어 설명을 받고, JSON으로 바로 내보냅니다.
